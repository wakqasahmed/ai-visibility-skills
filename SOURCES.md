# Source and Claim Ledger

Last reviewed: 2026-08-18

Each normative sentence in the skills cites one or more IDs below. Open the linked first-party source to verify the associated instruction. Source pages can change; re-check before production use.

| ID | Publisher | Source | Supports |
|---|---|---|---|
| `OPENAI-BOTS-01` | OpenAI | [Bots and crawlers](https://developers.openai.com/api/docs/bots) | GPTBot crawls the web to train OpenAI's models; OAI-SearchBot crawls to surface pages in ChatGPT's search results; ChatGPT-User fetches a page only when a user or Custom GPT asks ChatGPT to visit it. GPTBot and OAI-SearchBot can be blocked via `Disallow` rules scoped to their own user-agent token. |
| `ANTHROPIC-BOTS-01` | Anthropic | [Does Anthropic crawl data from the web, and how can site owners block the crawler?](https://support.claude.com/en/articles/8896518) | ClaudeBot crawls the web to build training datasets for Anthropic's models; Claude-User (the user-triggered fetcher) accesses a page only when a person asks Claude to visit it; Claude-SearchBot crawls to improve Claude's search-result quality. All of Anthropic's crawlers honor robots.txt `Disallow` rules scoped to their own user-agent token. |
| `PERPLEXITY-BOTS-01` | Perplexity | [Bots](https://docs.perplexity.ai/guides/bots) | PerplexityBot crawls and indexes pages to surface and link them in Perplexity's own search results and, per Perplexity's documentation, is not used to crawl content for AI foundation-model training; site owners control it with `Allow`/`Disallow` rules for the `PerplexityBot` user-agent token. |
| `GOOGLE-EXTENDED-01` | Google | [Google's common crawlers](https://developers.google.com/search/docs/crawling-indexing/google-common-crawlers) | `Google-Extended` is a standalone product token, not a separate crawling user agent, that lets a site owner control whether content Google crawls from their site may be used for training future Gemini models and for grounding in Gemini Apps and Vertex AI's Gemini API; it does not impact a site's inclusion in Google Search or its use as a ranking signal. |
| `APPLE-BOTS-01` | Apple | [About Applebot](https://support.apple.com/en-us/119829) | `Applebot-Extended` is a robots.txt token, separate from the `Applebot` search crawler, that controls whether content already fetched by Applebot may be used to train Apple's generative AI / Apple Intelligence models; disallowing it does not remove a page from Applebot-powered search results. |
| `COMMONCRAWL-CCBOT-01` | Common Crawl Foundation | [CCBot](https://commoncrawl.org/ccbot) | CCBot identifies itself with the user-agent string `CCBot/2.0`, respects robots.txt, and can be fully blocked with a `User-agent: CCBot` / `Disallow: /` rule. |
| `AMAZON-BOTS-01` | Amazon | [Amazonbot](https://developer.amazon.com/amazonbot) | Amazonbot crawls the web to improve Amazon's products and services and may be used to train Amazon AI models; it honors robots.txt `Allow`/`Disallow` directives as well as page-level `noindex`/`noarchive` meta tags and the `nofollow` link attribute. |
| `SCHEMA-PRODUCT-01` | Schema.org | [Product](https://schema.org/Product) | Defines the `Product` type and its properties (including `name`, `image`, `offers`, `sku`/`gtin`, `brand`) used to mark up an offered product or service. |
| `SCHEMA-ORGANIZATION-01` | Schema.org | [Organization](https://schema.org/Organization) | Defines the `Organization` type and its properties (including `name`, `url`, `logo`, `sameAs`, `contactPoint`) used to identify an organizational entity. |
| `SCHEMA-ARTICLE-01` | Schema.org | [Article](https://schema.org/Article) | Defines the `Article` type and its properties (including `headline`, `datePublished`, `dateModified`, `author`, `publisher`) used to mark up an article or blog post. |
| `SCHEMA-FAQPAGE-01` | Schema.org | [FAQPage](https://schema.org/FAQPage) | Defines the `FAQPage` type, whose `mainEntity` is a list of `Question` items each carrying an `acceptedAnswer`. |
| `SCHEMA-BREADCRUMBLIST-01` | Schema.org | [BreadcrumbList](https://schema.org/BreadcrumbList) | Defines the `BreadcrumbList` type: an ordered set of `itemListElement` entries (`ListItem`s with `position` and `item`) representing a page's breadcrumb trail. |
| `SCHEMA-LOCALBUSINESS-01` | Schema.org | [LocalBusiness](https://schema.org/LocalBusiness) | Defines the `LocalBusiness` type and its properties (including `name`, `address`, `geo`, `openingHoursSpecification`, `telephone`), with more specific subtypes (e.g. `Restaurant`) available where truthful. |
| `SCHEMA-SOFTWAREAPPLICATION-01` | Schema.org | [SoftwareApplication](https://schema.org/SoftwareApplication) | Defines the `SoftwareApplication` type and its properties (including `name`, `applicationCategory`, `operatingSystem`, `offers`). |
| `LLMSTXT-01` | llms.txt proposal | [The /llms.txt file](https://llmstxt.org) | Specifies the `llms.txt` convention: a Markdown file starting with an H1 project/site name and a short blockquote summary, followed by H2-delimited sections of Markdown links, placed at a site's root so language models can find curated, use-case-relevant content. |
| `GOOGLE-IMAGE-SEO-01` | Google | [Image SEO best practices](https://developers.google.com/search/docs/appearance/google-images) | Alt text is the most important attribute for describing an image to Google; it should be descriptive and contextual rather than generic or keyword-stuffed; standard `<img>`/`<picture>`/`srcset` markup is indexable while CSS background images are not. |
| `GOOGLE-IMAGE-SITEMAP-01` | Google | [Image sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps) | An image sitemap declares images via `<image:image>`/`<image:loc>` tags nested inside each `<url>` entry, using the `xmlns:image="http://www.google.com/schemas/sitemap-image/1.1"` namespace, up to 1,000 `<image:image>` entries per `<url>`; image URLs may be hosted on a different domain than the page. |
| `SCHEMA-IMAGEOBJECT-01` | Schema.org | [ImageObject](https://schema.org/ImageObject) | Defines the `ImageObject` type (`caption`, `embeddedTextCaption`, `exifData`, `representativeOfPage`, plus inherited `MediaObject`/`CreativeWork` properties); an entity's `image` property "can be a URL or a fully described `ImageObject`," with the fully described form used to carry metadata a bare URL cannot. |
